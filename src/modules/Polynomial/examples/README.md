# Polynomial examples

These standalone programs contain executable `Test_Method::OK` checks.
Run them from this directory with `easifem run <filename>` after installing
the current library. Building/installing and running require explicit user
permission under `AGENTS.md`. No examples are run by documentation generation.

The family Laplacian examples are documented gradient based workarounds:
the declared family Laplacian routines have no working implementations.
See [the module guide](../README.md) for conventions and known limitations.
